# Blocksmith for Windows

Blocksmith is a mixed-reality block crafting game for Meta Quest. These are Windows builds you can play with a mouse
and keyboard, on your own or in co-op with someone on a Quest.

## Download

**[Download the latest Windows build](https://github.com/Kindred-Spark/blocksmith-builds/releases/latest/download/Blocksmith-Windows.zip)**

Older builds are on the [Releases](https://github.com/Kindred-Spark/blocksmith-builds/releases) page.

## Play

1. Unzip it anywhere.
2. Run `Blocksmith.exe`. Windows may warn about an unknown publisher; choose "More info", then "Run anyway".
3. Click in the window to start. The key help is in the top-left corner.

These are development builds: expect rough edges.
